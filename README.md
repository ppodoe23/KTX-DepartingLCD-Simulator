# KTX 객실 LCD 안내화면 (웹 재현)

충주발 부발행 KTX-이음 738열차의 출발 안내 화면을 웹으로 재현한 프로젝트입니다.

**재생 순서:** 출발 안내 3D 인트로 → **노선도 지도** (출발역에서 줌아웃하며 노선이 역 순서대로 그려지고, 첫 정차역으로 줌인) → 정차역 안내 (풍선 링이 좌우 번갈아 나옴) → 화면 어두워짐 → 안전 안내 문구 → 처음부터 반복

## 실행 (VS Code)

1. 이 폴더를 VS Code로 엽니다.
2. 확장 **Live Server**(ritwickdey.LiveServer)를 설치합니다.
3. `index.html`을 우클릭하고 **Open with Live Server**를 누릅니다.

> `index.html`을 더블클릭해서 `file://`로 열면 glb와 모듈 로딩이 막힙니다. 꼭 로컬 서버로 여세요.
> three.js와 폰트는 CDN에서 받아오므로 인터넷 연결이 필요합니다.

## 3D 모델 넣기

`models/` 폴더에 넣으세요.

| 파일 | 용도 |
|---|---|
| `models/station_sign.glb` | 역명판 (인트로 왼쪽) |
| `models/train.glb` | 열차 (인트로 뒤편에 정차 + 선로 플라이바이) |

파일 이름이나 경로가 다르면 `js/config.js`의 `models.*.url`을 고치세요.
파일이 없거나 로드에 실패하면 기본 도형으로 대신 그려집니다.

모델은 크기와 방향을 자동으로 맞춥니다.

- **역명판:** `height`(m)에 맞춰 스케일하고 바닥을 지면에 붙입니다. 정면이 카메라 쪽(+Z)이 아니면 `rotationY`를 90 / 180 / -90으로 바꾸세요.
- **열차:** 높이 `height`(기본 4m)에 맞춰 스케일하므로 객차 수와 상관없이 실제 비율이 유지됩니다. `length`에 숫자를 넣으면 전체 길이 기준으로 바뀝니다. 앞뒤가 반대로 달리면 `forwardAxis`를 `'-x'`나 `'-z'`로 바꾸세요. 레일 위로 뜨거나 묻히면 `yOffset`으로 보정하세요.
- **곡선 주행:** 열차는 객차 사이 틈을 찾아 객차별로 나뉘고, 곡선에서 객차마다 따로 꺾입니다. 콘솔에 `객차 n량으로 분리`가 출력되니 수가 다르면 `carCount`로 직접 지정하세요.
- **앞뒤 방향:** 끝이 뾰족하게 낮아지는 쪽을 앞머리로 판단해 자동으로 맞춥니다. 거꾸로 달리면 `forwardAxis`를 `'x'`, `'-x'`, `'z'`, `'-z'` 중 하나로 직접 지정하세요.
- **모델이 너무 작게 나올 때:** 로블록스 Baseplate처럼 넓은 판이나 멀리 떨어진 파트가 섞여 있으면 자동으로 빼고 본체 크기만 잽니다. F12 → Console에 `[KTX LCD] 열차: … 본체 크기 …, 제외한 파트: …`가 출력되니 확인해 보세요. 그래도 크기가 이상하면 `ignoreMeshes`에 뺄 파트 이름을 적거나 `scale`(배율)로 조절하세요.
- **역명판 글씨 자동:** 모델에서 파란 판을 찾아 그 앞면에 출발역 이름(한글, 밑줄, 영문 | 한자)을 자동으로 붙입니다. 모델에 글씨가 이미 있으면 `textMode: 'none'`으로 끄세요. 글씨가 판 옆면에 붙거나 안 보이면 `rotationY`를 90 / -90 / 180으로 바꿔 보세요.
- **역명판 글씨를 코드로 그리기 (메쉬 지정):** glb 안의 판 메쉬 이름을 `textMeshName`에 적으면, 그 메쉬에 출발역 이름(충 주 / Chungju | 忠州)을 그린 텍스처를 입힙니다.

## 사이트에서 노선 바꾸기

화면을 한 번 클릭한 뒤 S 키를 누르면 설정창이 열려요 (S 또는 Esc로 닫기).

- 출발역, 정차역, 종착역과 각 시각을 바꾸고 [적용]을 누르면 처음부터 다시 재생돼요.
- 정차역은 [+ 정차역 추가]로 늘리고, ▲▼로 순서를 바꾸고, ✕로 지울 수 있어요.
- 목록에 없는 역은 영문, 위도, 경도 칸이 나타나니 함께 적어 주세요.
- 시각은 기본적으로 **현재 시각 기준 자동 생성**이에요. 출발시각은 지금 시각이고, 이후 역은 `js/data/travelTimes.js`의 역간 소요시간표(실제 시간표 기준)와 정차시간으로 계산해요. 반복 재생할 때마다 새로 만들어요.
- 소요시간표는 노선별로 이웃한 역 사이 주행시간(분)을 적어 둔 것이라, 숫자를 고치거나 구간을 추가하면 바로 반영돼요. 표에 없는 구간은 직선거리로 추정하고 콘솔에 알려줘요.
- '출발·도착 시각 직접 입력'을 켜면 각 칸에 입력한 시각을 그대로 써요.
- 좌상단 날짜·시각은 현재 시각이에요 (config.js의 `clock`).
- 설정은 브라우저에 저장돼요. [기본값]을 누르면 config.js 노선으로 돌아가요.
- [링크 복사]를 누르면 지금 노선이 담긴 주소가 복사돼요. 다른 PC에서 그 주소로 열면 같은 노선으로 재생돼요.

## config.js에서 노선 바꾸기 (출발역 · 정차역 · 도착역)

`js/config.js`의 `route`에 역 이름과 시각만 적으면 됩니다.

```js
route: {
  origin:      { name: '수서', depart: '14:30' },
  stops: [
    { name: '평택지제', arrive: '14:50' },
    { name: '천안아산', arrive: '15:03' },
  ],
  destination: { name: '부산', arrive: '16:56' },
},
```

- 영문 표기, 역명판 한자, 지도 좌표는 `js/data/stations.js`(KTX·SRT·KTX-이음 주요 역 약 80개)에서 자동으로 찾습니다.
- 링 가운데의 도 이름(경기도, 충청북도…)은 좌표로 자동 판별합니다.
- 목록에 없는 역은 `en`, `lat`, `lon`을 직접 적어 주세요. 좌표가 없으면 앞뒤 역 사이로 추정합니다.
- 어떤 값이든 직접 적으면 자동값보다 우선합니다: `en`, `hanja`, `province`, `sub`(괄호 표기, 예: 울산역**(통도사)**), `labelSide`(지도 역 이름 위치).
- 역 좌표는 지도 표시용 근사값입니다. 노선 선은 역과 역을 부드러운 곡선으로 잇습니다. 실제 선로처럼 꺾이게 하려면 역에 `via: [[위도, 경도], ...]` 경유점을 넣으세요. 노선도 지도와 정차역 화면의 캐릭터 이동 경로에 모두 적용됩니다.

## 서울남산체 (출발 화면)

출발 화면(출발 카드, 역명판 글씨)은 서울남산체, 출발시간 숫자는 7세그먼트 디지털 숫자를 씁니다.

- `fonts/SeoulNamsanM.woff`(보통 굵기)가 들어 있어 바로 적용됩니다.
- 굵은 글씨(출발, 출발역명, 역명판)를 진짜 B / EB 굵기로 쓰려면, 서울시 서울서체 배포 페이지에서 받은 파일을 `fonts/SeoulNamsanB.ttf`, `fonts/SeoulNamsanEB.ttf`(woff, woff2도 가능)로 넣으세요. PC에 서울남산체가 설치되어 있으면 그것을 먼저 씁니다.
- 파일이 없으면 M 굵기로 대체됩니다.
- 출발시간 숫자를 서울남산체로 바꾸려면 `departureTimeStyle: 'font'`로 설정하세요.
- 역명판이 오른쪽, 카드가 왼쪽인 구도(수서발 영상)는 `intro.signSide: 'right'`로 설정하세요.

## 그 밖의 설정

`js/config.js`에서 바꿀 수 있습니다.

- 노선도 지도 범위 (`map.view`: `'auto'` / `'korea'` / `'route'`)
- 좌상단 시계 (`clock.mode`: `'live'`면 현재 시각, `'fixed'`면 영상 속 시각)
- 각 장면 길이 (`timing`)
- 안전 안내 문구와 하단 띠 문구 (`notice`)
- 안전 안내 뒤에 이어 틀 영상 (`notice.afterVideo`, mp4)

## 개발용 단축 기능

| 주소 / 키 | 동작 |
|---|---|
| `?start=map` | 노선도 지도부터 시작 |
| `?start=stops` | 정차역 안내부터 시작 |
| `?start=notice` | 안전 안내부터 시작 |
| `?freeze=7.5` | 인트로 7.5초 장면에서 멈춤 (카메라·모델 위치 확인용) |
| `?start=map&mapfreeze=6` | 노선도 지도 6초 장면에서 멈춤 |
| `R` 키 | 처음부터 다시 |

## 파일 구성

```
index.html
css/style.css      화면 디자인 (1280x720 기준, 창 크기에 맞춰 자동 확대·축소)
js/config.js       ← 주로 고칠 파일
js/main.js         전체 시퀀스, 시계, 안전 안내
js/settings.js     사이트 노선 설정창
js/travel.js       역간 소요시간 계산 (소요시간표 최단 경로 합산)
js/data/travelTimes.js  노선별 역간 소요시간표 ← 직접 고칠 수 있음
js/route.js        노선 설정 → 역 정보 (DB 조회, 도 이름 판별)
js/routeMap.js     노선도 지도 화면
js/routePath.js    노선 경로 곡선 (지도·정차역 화면 공용)
js/data/stations.js  역 DB (영문·한자·좌표)
js/data/koreaMap.js  한반도 시도 경계 지도 데이터 (Natural Earth 1:10m)
js/data/sigungu.js   시군구 경계 (통계청 2013) — 출발 화면에서 출발역 시군구가 3D로 솟아오르는 데 사용
fonts/             서울남산체
js/intro3d.js      three.js 3D 인트로 (역명판, 출발 카드, 고가 선로, 열차)
js/stopGuide.js    정차역 안내 화면과 풍선 링 애니메이션
js/util.js
models/            glb 넣는 곳
```
